# 보면대 — 악보 뷰어

이미지·PDF 악보를 폴더와 곡목록으로 정리하고, 필기·자동 넘김·메트로놈·튜너·건반·녹음으로 연주하는 웹앱입니다.

**앱 주소:** https://jieungood.github.io/Music/

## 아이패드에 설치
1. 위 주소를 아이패드 **Safari**로 엽니다.
2. 공유 버튼(네모에 ↑) → **홈 화면에 추가** → **추가**
3. 홈 화면의 '보면대' 아이콘으로 열면 전체 화면 앱으로 실행되고, 인터넷 없이도 열립니다.

악보·필기·녹음은 기기 안에만 저장됩니다. 앱을 지우기 전에는 ⚙ → 백업 저장으로 백업해 두세요.
